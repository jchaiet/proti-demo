# Proti v0.3.1

**Release type:** Security & Maintenance  
**Release date:** November 3, 2026  
**Previous release:** v0.3.0

## Overview

Proti v0.3.1 focuses on dependency security, workspace stability, build compatibility, and continuous integration improvements.

This maintenance release preserves the functionality introduced in v0.3.0 while significantly reducing reported dependency vulnerabilities across the Next.js website and Sanity Studio.

## Security Improvements

The dependency security audit was reduced from 90 initial findings to 3 remaining findings.

### Dependency Updates

- Updated Next.js to 16.4.3.
- Updated Sanity to 6.21.0.
- Updated Vitest to 4.1.12.
- Updated vulnerable Vite 6 dependencies to 6.4.5.
- Updated Sharp dependency resolution.
- Applied targeted security overrides for vulnerable transitive dependencies.
- Addressed vulnerabilities involving Undici, UUID, js-yaml, smol-toml, brace-expansion, source-map-js, and other dependencies.

### Remaining Security Findings

**Zod — High severity**

- Package: `zod@3.25.76`
- Introduced by: `sanity-plugin-media`
- Advisory: `GHSA-mrhx-c7xc-m3w5`
- Status: Unresolved; upstream compatibility remediation required.

Sanity Media uses Zod 3 for asset metadata, folder, and tag form validation.

The inspected code indicates that this validation is associated with CMS editing functionality rather than Proti's public-facing application. However, complete isolation of the vulnerable validation path has not been established.

A forced Zod 4 upgrade was avoided because the plugin currently declares a Zod 3 dependency.

Access to media administration should remain restricted to authorized Studio users. The dependency will continue to be monitored for a compatible security update.

**Minimatch — Moderate severity**

- Versions: 3.1.5 and 10.2.6
- Introduced by: ESLint-related development dependencies.
- Advisory: `GHSA-g3hv-75wg-m249`
- Status: Unresolved in the full dependency audit.

The vulnerable production-audit dependency through Sanity CLI was addressed with a targeted override.

Remaining findings are associated with development tooling. Further major-version overrides were deferred pending upstream compatibility improvements.
