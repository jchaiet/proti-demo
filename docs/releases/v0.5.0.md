# Proti v0.5.0 — Deterministic Visual Regression

**Status:** Release candidate; final regression and release tag pending.

## Summary

v0.5.0 separates screenshot comparisons from published Sanity content. Visual
fixtures use CMS-shaped, version-controlled test data through real Proti block
renderers, mappers, layouts and Mino UI components.

## Scope

- Hero, Content/Rich Text, Grid, Article/Resource Cards, Accordion, Tabs,
  Carousel, and Header/Footer/Navigation visual fixtures.
- Desktop and mobile state screenshots, including keyboard and expanded states.
- Local SVG fixture assets and a gated `/visual-fixtures/*` route namespace.
- Separate CI builds: CMS-backed smoke with fixtures disabled, and deterministic
  visual comparisons with fixtures enabled.
- Updated `proti:visual:init` and `proti:check` baseline lifecycle (37 images).
- Optional legacy CMS visual commands remain available for manual diagnostics.

## Safety and compatibility

`PROTI_VISUAL_FIXTURES=1` is a **test-build-only** switch. Public production
builds must not enable it. Smoke tests must continue to exercise real CMS
pages. The production Site's host-matching logic is unchanged.

## Migration notes

Fresh projects: run `pnpm proti:visual:init` after initialization. Existing
projects with PNG baselines must opt in to regeneration with `--force`.
Compare updated screenshot images before committing. Snapshot approval is
intentional, never an automatic CI action.
